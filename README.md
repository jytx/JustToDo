# JustToDo

一个**本地优先**的跨平台待办 / 任务管理桌面应用。

基于 **Tauri 2** + **Vue 3** + **Arco Design Vue** 构建，数据存储在本地 SQLite，无需联网、无需账号，完全离线可用。

## ✨ 功能特性

### 📋 任务管理
- **完整 CRUD** — 创建、编辑、完成、删除任务
- **多级子任务** — 树形结构展开，支持多级嵌套
- **优先级** — 无 / 低 / 中 / 高（四档色点标记）
- **日期范围** — 开始日期 + 结束日期，支持跨时间段任务
- **循环任务** — 每日 / 每周 / 每月等规则，自动生成下一周期
- **提醒** — 基于截止时间偏移的本地通知，到点提醒
- **拖拽排序** — 任务、分组、清单均支持手动拖拽排序

### 🗂️ 清单与组织
- **清单 / 目录树** — 多级嵌套，支持颜色标记
- **任务分组（Group）** — 清单内分组管理、跨组拖拽
- **标签系统** — 跨清单横向分类，任务-标签多对多关联
- **智能视图** — 今天 / 即将到来 / 全部，自动按截止日期聚合
- **归档** — 清单 / 笔记支持子树级归档与恢复，归档区独立展示
- **任务计数** — 侧边栏实时显示各清单与智能视图的未完成数

### 📌 多视图
- **列表视图** — 经典任务列表，支持分组
- **看板视图** — 按优先级或分组分列，跨列拖拽流转
- **时间线（甘特图）** — 横条按日期定位，拖拽改期，列宽可调
- **日历视图** — 周 / 月 / 年三档（FullCalendar，中文本地化）
- **任务详情面板** — 可拖拽宽度，面包屑导航，ESC 关闭

### 📝 富文本与附件
- **类 Notion 编辑器** — 基于 Tiptap 3，支持：
  - 加粗 / 斜体 / 删除线 / 标题 / 引用 / 列表 / 任务列表
  - 代码块（语法高亮）/ 行内代码 / 分隔线
  - 图片粘贴 / 拖拽上传 / 拖拽缩放 / 点击预览（多图切换 + 滚轮缩放）
  - 斜杠命令（`/`）、浮动工具栏、块级拖拽手柄
- **附件系统** — 任意类型文件保存（按分类归档目录）、文本预览、在文件管理器中定位、复制路径，支持自定义附件根目录

### 🗒️ 笔记 / 便签
- 复用 tasks 表，独立成区（与清单为两棵树），预置「默认笔记本」
- 保留富文本 / 标签 / 子笔记 / 附件 / 拖拽排序 / 归档
- 与任务共用全局标签与全局搜索

### 🎯 习惯打卡
- 每日习惯追踪，按时段（早 / 午 / 晚）分组
- emoji 图标、连续天数与总天数统计

### 🧩 模板
- 任务 / 笔记两类模板，占位符替换（含中文日期）
- 一键应用，任务走默认清单、笔记走当前笔记本

### ⚡ 效率工具
- **全局搜索** — `⌘K` 命令面板，跨任务与笔记
- **快速添加** — `⌘⇧A` 任意位置唤起，可带默认清单 / 日期
- **批量操作** — `Shift` / `⌘` 多选 + 右键批量菜单
- **清单生成计划** — 周期性按模板路径自动生成清单 / 笔记，内置中国法定节假日识别（工作日判定）、预览、手动触发

### 🤖 AI 能力（可选）
- 支持 **OpenAI 兼容** 与 **Anthropic** 两种协议，连接测试
- **每日 / 每周小结**（流式输出）
- **范围总结** — 按清单 / 目录 / 多选任务总结（超长自动裁剪）
- **自然语言建任务**（多意图路由：建任务 / 建笔记 / 总结清单 / 智能总结）
- **大任务拆解** — 自动拆分为子任务
- **文本提取** — 从一段文字提取多个待办
- **文本润色** — 保留 HTML 结构的流式润色
- 全套配置与提示词在设置页可自定义

### 🎨 体验
- **深色模式** — 浅色 / 深色 / 跟随系统，Arco 主题适配，可切换强调色
- **快捷键** — 搜索 / 快速添加 / AI 小结 / 切换主题 / 新建 / 缩放
- **原生菜单** — 应用 / 编辑 / 视图 / 窗口 / 帮助，含打开数据 / 日志 / 附件目录
- **可拖拽布局** — 侧边栏收起、任务详情面板宽度可调
- **可配置启动视图** — 设置启动时默认打开的页面
- **MCP 集成** — 应用本身作为 MCP Server（名为 JustToDo）对外暴露能力

## 📦 安装与运行

### 环境要求

- [Node.js](https://nodejs.org/) 18+
- [Rust](https://www.rust-lang.org/)（stable）
- [Tauri 2 前置依赖](https://v2.tauri.app/start/prerequisites/)

### 快速开始

> 项目约定：所有 Run & Debug 操作统一使用 `scripts/` 目录下的 `.sh` 脚本启停，避免直接调用 npm / cargo。

```bash
# 1. 安装依赖（前端 + Rust）
./scripts/install-deps.sh

# 2. 开发模式（启动桌面窗口 + 前端热更新 + Rust）
./scripts/dev.sh

# 3. 类型检查
./scripts/type-check.sh

# 4. Rust debug 构建
./scripts/build-debug.sh
```

### 对应的 npm 命令（脚本内部封装）

```bash
npm run dev              # 仅前端开发服务器（不启动原生窗口）
npm run tauri:dev        # Tauri 桌面应用开发模式
npm run tauri:build      # 前端 build + Tauri 打包
npm run tauri:build:mac  # 打包 macOS（app + dmg）
npm run tauri:build:win  # 打包 Windows（msi + nsis）
npm run rust:check       # cargo check
```

```
│   ├── views/                   # 路由级页面（列表/看板/时间线/日历/笔记…）
│   ├── stores/                  # Pinia 状态管理（task/list/tag/habit/…）
│   ├── composables/             # 组合式钩子（拖拽、快捷键、主题、视图偏好…）
│   ├── api/                     # IPC 封装（db.ts / ai.ts / listSchedule.ts）
│   ├── types/                   # TS 类型定义
│   ├── utils/                   # 工具函数（日期、颜色、拖拽、图片上传…）
│   ├── composables/             # 组合式钩子
│   ├── layouts/                 # 三栏布局
│   ├── router/                  # Vue Router（hash 模式）
│   └── styles/                  # 主题与排版样式
├── src-tauri/                   # Rust 后端
│   ├── src/
│   │   ├── commands.rs          # Tauri IPC 命令（80+ 个）
│   │   ├── models.rs            # 数据模型
│   │   ├── ai/                  # AI Provider 适配（OpenAI / Anthropic）
│   │   ├── list_schedule/       # 清单生成计划（含节假日处理）
│   │   ├── db/                  # SQLite 连接池 + 幂等迁移
│   │   │   └── migrations/      # SQL / 代码迁移文件
│   │   ├── menu.rs              # 原生菜单
│   │   └── lib.rs               # App 入口（插件 + 定时器 + invoke_handler）
│   ├── capabilities/            # Tauri 2 权限配置
│   └── tauri.conf.json          # Tauri 配置
├── scripts/                     # Run & Debug 启停脚本
├── discuss/                     # 功能设计与计划文档
└── package.json
```

## 🎨 设计

- **视觉风格**：Refined Minimal — 暖白背景（`#FAFAF7`）+ 靛蓝强调（`#4F46E5`）
- **字体**：Fraunces（标题）· Geist（正文）· JetBrains Mono（代码）
- **布局**：三栏式 — 侧边栏（240px，可收起）· 主区 · 任务详情面板（360px+，可拖拽）
